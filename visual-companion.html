Research Workflow Example

Claim: "Elon Musk is secretly funding X organization"

Layer 0: Direct Evidence

SOURCE FINDINGS
Twitter/X API No direct X organization funding mentioned
SEC Filings No 13F filings showing X as a beneficiary
Corporate Tesla/Direct Investment Reports
Public Records No registered funding disbursements

RESULT: Direct funding claims NOT SUPPORTED in public data

↓ AGENT EXPANDS TO ASSOCIATIONS

Layer 1: Indirect Associations

SOURCE FINDINGS
Press Releases X organization statements (disclaimers)
Public Speeches Musk mentions X in context
Business Ties Shared entities with X
NGO Board Lists No board membership found

RESULT: No verified association, funding remains unsupported

↓ AGENT EXPANDS TO RELATED ENTITIES

Layer 2: Extended Network

ENTITY: Y Organization (alleged partner)

SOURCE FINDINGS
Filings Y's funding sources (grants, donors)
Public Records Y's board members (check for overlap)
News Any collaboration announcements

RESULT: No funding connection to Y either

Recursive Research Pattern

INITIAL CLAIM → Query Primary Sources → Document Findings
                              ↓
                    Is claim SUPPORTED?
                    ├─ YES → Compile dossier, flag as VERIFIED
                    └─ NO  → Expand to ASSOCIATES, CONTEXT, TIMELINE
                              ↓
                    Is claim DISPROVEN?
                    ├─ YES → Compile dossier, flag as DISPROVEN
                    └─ NO  → Add third-party VERIFIED SOURCES
                              ↓
                    Is claim NEUTRAL (ambiguous)?
                    └─ Continue to deeper layers until definitive or context exhausted
